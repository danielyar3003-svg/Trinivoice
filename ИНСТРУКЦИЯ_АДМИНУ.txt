TriniVoice — инструкция для админа
==================================

Ты запускаешь «голосовой сервер» (ретранслятор). Через него игроки слышат друг
друга. Он будет работать на бесплатном сервере Oracle круглосуточно.

Что понадобится:
  * компьютер с Windows 10 или 11;
  * банковская карта (Oracle только проверяет её, бесплатный тариф денег не берёт);
  * файл TriniVoice-0.4.0-relay.zip (лежит рядом с этой инструкцией);
  * минут 30–40 в первый раз.

Весь путь:
  1. Создать сервер в Oracle.
  2. Открыть в Oracle порт для голоса.
  3. Подключиться к серверу с компьютера.
  4. Залить файл и запустить установку (одна команда).
  5. Скачать готовый архив для игроков и раздать его.
  6. (по желанию) Настроить пароли раций и свой сервер Trinity.
  7. Научиться командам админа в игре.


=================================================================
ШАГ 1. Создать сервер в Oracle
=================================================================
1. Открой https://cloud.oracle.com и нажми «Sign Up» (регистрация).
2. Заполни данные. Регион (Home Region) выбери поближе к игрокам,
   например Germany Central (Frankfurt). ПОМЕНЯТЬ ЕГО ПОТОМ НЕЛЬЗЯ.
3. Войди в консоль Oracle.
4. Слева вверху меню (три полоски) -> Compute -> Instances.
5. Нажми «Create instance».
6. Имя (Name): trinivoice.
7. Блок «Image and shape» -> «Edit»:
   * Image -> «Change image» -> Ubuntu -> выбери «Canonical Ubuntu 24.04»
     (именно 24.04!) -> «Select image».
   * Shape -> «Change shape» -> выбери вариант с надписью «Always Free eligible»:
     VM.Standard.E2.1.Micro  или  VM.Standard.A1.Flex (1 OCPU, 6 GB).
     -> «Select shape».
8. Блок «Networking»: оставь «Create new virtual cloud network» и
   «Create new public subnet». Галочка «Assign a public IPv4 address» — ВКЛ.
9. Блок «Add SSH keys»: выбери «Generate a key pair for me» и нажми
   «Save private key». Скачается файл вида ssh-key-2026-...key.
   ЭТО КЛЮЧ ОТ СЕРВЕРА. Не теряй и никому не отправляй.
10. Нажми «Create». Подожди 1–2 минуты, пока статус станет зелёным «RUNNING».
11. На странице сервера найди «Public IP address» — например 141.147.12.34.
    Запиши его. Дальше в инструкции это ТВОЙ_IP.

Если Oracle пишет «Out of capacity» — попробуй другой Shape из Always Free
или повтори через пару часов.


=================================================================
ШАГ 2. Открыть порт для голоса
=================================================================
1. На странице сервера в блоке «Primary VNIC» нажми на ссылку Subnet
   (что-то вроде subnet-2026...).
2. Слева или внизу найди «Security Lists» и нажми «Default Security List...».
3. Нажми «Add Ingress Rules» и заполни:
      Source CIDR:             0.0.0.0/0
      IP Protocol:             UDP
      Destination Port Range:  7790
   Остальное не трогай.
4. Нажми «Add Ingress Rules».

Больше ничего не открывай.


=================================================================
ШАГ 3. Подключиться к серверу
=================================================================
1. Создай на компьютере папку, например C:\oracle
2. Положи туда:
   * скачанный ключ — переименуй его в oracle.key
   * файл TriniVoice-0.4.0-relay.zip
3. Открой эту папку. Нажми правой кнопкой мыши по пустому месту:
   * Windows 11: «Открыть в терминале»
   * Windows 10: зажми Shift и нажми правой кнопкой -> «Открыть окно PowerShell здесь»
4. Скопируй и вставь эту команду (правой кнопкой мыши вставляется), нажми Enter:

   icacls .\oracle.key /inheritance:r /grant:r "${env:USERNAME}:R"

   (это нужно один раз: Windows запрещает другим читать твой ключ)

5. Теперь подключись (замени ТВОЙ_IP на свой IP из шага 1):

   ssh -i .\oracle.key ubuntu@ТВОЙ_IP

6. Спросит «Are you sure you want to continue connecting?» — напиши yes и Enter.
7. Получилось, если строка стала такой:  ubuntu@trinivoice:~$
   Это окно — командная строка твоего сервера. Не закрывай его.


=================================================================
ШАГ 4. Залить файл и установить
=================================================================
1. Открой ВТОРОЕ окно терминала в папке C:\oracle (как в шаге 3, пункт 3).
2. Отправь файл на сервер (замени ТВОЙ_IP):

   scp -i .\oracle.key TriniVoice-0.4.0-relay.zip ubuntu@ТВОЙ_IP:~

3. Вернись в ПЕРВОЕ окно (где ubuntu@trinivoice:~$) и выполни по очереди:

   sudo apt-get install -y unzip

   unzip -o TriniVoice-0.4.0-relay.zip -d trinivoice

   cd trinivoice

   sudo bash deploy/install-ubuntu.sh

4. Подожди 2–3 минуты. Бегут строки «== 1/7 ... == 7/7».
5. В середине появится строка «Ключ администратора» и длинный набор букв и цифр.
   СКОПИРУЙ ЕГО И СОХРАНИ (например, в заметки). Это твой пароль админа.
6. В конце будет рамка «ГОТОВО. Ретранслятор работает.» и
   «active (running)» зелёным. Значит, голосовой сервер запущен.

Если ключ потерялся, посмотреть его снова:
   sudo grep key /etc/trinivoice/config.json


=================================================================
ШАГ 5. Забрать архив для игроков и раздать
=================================================================
Установка сама собрала архив, в который УЖЕ ВПИСАН адрес твоего сервера.
Игрокам не нужно ничего настраивать.

1. Во ВТОРОМ окне (C:\oracle) выполни (замени ТВОЙ_IP):

   scp -i .\oracle.key ubuntu@ТВОЙ_IP:~/TriniVoice-players.zip .

   (точка в конце — значит «сюда»)

2. В папке C:\oracle появился файл TriniVoice-players.zip.
3. Раздай его игрокам (Discord, ВК, группа). Внутри есть инструкция
   ПРОЧИТАЙ_МЕНЯ.txt — игроку достаточно её.
4. Проверь сам: установи этот архив себе по инструкции игрока, зайди в игру.
   В чате должно быть «подключено к голосовому серверу».


=================================================================
ШАГ 6. Настройки (по желанию)
=================================================================
В ПЕРВОМ окне:

   sudo nano /etc/trinivoice/config.json

Откроется файл настроек. Двигайся стрелками. Что можно поменять:

* Закрытые частоты рации для фракций:
     "radioPasswords": { "911.0": "lspd-пароль", "912.0": "ems-пароль" },
  Пароль частоты скажи лидеру фракции.

* Только твой сервер Trinity (чтобы чужие не пользовались твоим голосовым сервером):
     "allowedRooms": [ "IP_СЕРВЕРА_TRINITY:7777" ],
  IP сервера Trinity видно в SA-MP в списке серверов.
  Если не уверен — оставь [] (пусто = любой сервер).

* Админ-команды только с твоего домашнего IP:
     "adminIps": [ "ТВОЙ_ДОМАШНИЙ_IP" ],
  Узнать домашний IP: открой сайт 2ip.ru. Если IP меняется — оставь [].

Сохранить: Ctrl+O, потом Enter. Выйти: Ctrl+X.
Применить:

   sudo systemctl restart trinivoice

Если после перезапуска не работает — значит, ошибка в запятых или кавычках.
Посмотри журнал (шаг «Каждый день» ниже) — там будет написано, где ошибка.


=================================================================
ШАГ 7. Команды админа в игре
=================================================================
Один раз впиши свой ключ из шага 4:

   /tv adminkey ТВОЙ_КЛЮЧ

Дальше (НИК — ник игрока, как в игре):

   /tv admin mute НИК 30     выключить ему голос на 30 минут (0 = навсегда)
   /tv admin unmute НИК      вернуть голос
   /tv admin ban НИК 0       забанить в голосовом чате (по нику и по IP), 0 = навсегда
   /tv admin unban НИК       разбанить
   /tv admin kick НИК        отключить (он сможет зайти снова)

Если 5 раз ввести неверный ключ — команды с твоего IP не будут работать 15 минут.

Жалобы игроков приходят в файл на сервере. Посмотреть:

   sudo cat /var/lib/trinivoice/reports.jsonl

Запись голоса нарушителя сохраняется У ИГРОКА, который пожаловался:
moonloader\config\trinivoice\reports\ — попроси её прислать.


=================================================================
КАЖДЫЙ ДЕНЬ / ЕСЛИ ЧТО-ТО СЛУЧИЛОСЬ
=================================================================
Подключиться к серверу: шаг 3, пункты 3 и 5.

Работает ли:          sudo systemctl status trinivoice
Журнал (выход Ctrl+C): sudo journalctl -u trinivoice -f
Перезапустить:        sudo systemctl restart trinivoice
Остановить:           sudo systemctl stop trinivoice

Обновить на новую версию:
  залей новый архив (шаг 4, пункт 2) и повтори пункт 3 шага 4.
  Настройки, баны и жалобы сохранятся. Потом раздай игрокам новый
  TriniVoice-players.zip (шаг 5).

Резервная копия (баны, жалобы, настройки) — во ВТОРОМ окне, две команды:
  ssh -i .\oracle.key ubuntu@ТВОЙ_IP "sudo tar czf backup.tgz /etc/trinivoice /var/lib/trinivoice && sudo chown ubuntu backup.tgz"
  scp -i .\oracle.key ubuntu@ТВОЙ_IP:~/backup.tgz .

Сервер пропал / не отвечает:
  Oracle иногда останавливает бесплатный сервер, если он долго почти не нагружен.
  Зайди в консоль Oracle -> Compute -> Instances -> trinivoice -> «Start».
  Голосовой сервер запустится сам.

У игроков «нет связи»:
  1) sudo systemctl status trinivoice — должно быть active (running);
  2) проверь правило из шага 2 (UDP, порт 7790);
  3) у игрока в ini правильный адрес (или пусть напишет /tv server ТВОЙ_IP 7790).


=================================================================
БЕЗОПАСНОСТЬ — ЧТО НУЖНО ЗНАТЬ
=================================================================
Защищено:
  * никто не может говорить от чужого имени, подделав IP;
  * через твой сервер нельзя устроить DDoS другим;
  * IP игроков не видны другим игрокам;
  * подбор ключа админа блокируется;
  * программа работает без прав администратора сервера, открыт один порт,
    обновления безопасности Ubuntu ставятся сами.

Нужно знать честно:
  * Голос НЕ шифруется. Ты как владелец технически видишь ники, ID, координаты
    и IP игроков. Скажи об этом игрокам.
  * Ключ админа никому не давай. Если утёк — поменяй его в
    /etc/trinivoice/config.json (поле "key") и перезапусти.
  * Сторонние скрипты могут быть запрещены правилами Trinity RP.
    Согласуй TriniVoice с администрацией сервера ДО раздачи игрокам.
  * Раздавай только свой архив. Попроси игроков не брать «копии» у других.
