TriniVoice — голосовой чат для Trinity RP
=========================================

Установка делается ОДИН раз и занимает 5 минут.


ШАГ 1. Проверь, есть ли у тебя MoonLoader
------------------------------------------
1. Открой папку с игрой. Это папка, где лежит файл gta_sa.exe.
2. Посмотри: есть там папка moonloader?

   ЕСТЬ  -> иди к шагу 2.
   НЕТ   -> сначала установи MoonLoader и SAMPFUNCS.
            Их скачивают на сайте blast.hk (в поиске сайта напиши MoonLoader).
            Там же написано, как их поставить. Потом вернись сюда.


ШАГ 2. Распакуй архив в папку с игрой
-------------------------------------
1. Нажми ПРАВОЙ кнопкой мыши на архив TriniVoice (файл .zip).
2. Выбери «Извлечь всё...».
3. Нажми «Обзор...» и выбери папку с игрой (где gta_sa.exe).
4. Нажми «Извлечь».
5. Если Windows спросит про файлы с такими же именами — нажми «Заменить».

Проверка: в папке moonloader появился файл trinivoice.lua.


ШАГ 3. Зайди в игру
-------------------
1. Запусти SA-MP и зайди на сервер Trinity RP.
2. В чате появится зелёная надпись:
      [TriniVoice] v0.4.0 загружен
3. Через пару секунд:
      [TriniVoice] подключено к голосовому серверу

   Если вместо этого ничего нет или пишет «нет связи» — смотри
   раздел «ЕСЛИ НЕ РАБОТАЕТ» в конце.


ШАГ 4. Разреши микрофон
-----------------------
Если тебя не слышат, а ты всё делаешь правильно:
Пуск -> Параметры -> Конфиденциальность -> Микрофон.
Включи «Доступ к микрофону» и «Разрешить классическим приложениям доступ к микрофону».

ВСЁ! Можно говорить.


========================================
          КАК ПОЛЬЗОВАТЬСЯ
========================================

ГОВОРИТЬ
  Зажми X и говори. Отпустил — тебя больше не слышно.
  Тебя слышат только игроки рядом (у кого тоже стоит TriniVoice).
  Слева на экране написано «В ЭФИРЕ», пока тебя слышат.
  Над головой того, кто говорит, видно (( голос )).

ГРОМКОСТЬ ГОЛОСА — клавиша B
  Шёпот   — слышно на 3 метра
  Обычный — на 15 метров
  Крик    — на 40 метров
  В полицейской машине, скорой или пожарке крик = мегафон на 60 метров.

РАЦИЯ
  /tv radio 100.0     включить рацию на частоте 100.0 (частоту скажет лидер)
  Зажми Z             говорить в рацию. Слышат все на этой частоте, даже далеко
  /tv radio off       выключить рацию
  /tv radiopass 1234  пароль, если частота закрытая (пароль скажет лидер)

ТЕЛЕФОН
  /tv call 25         позвонить игроку с ID 25
  /tv accept          ответить на звонок
  /tv hangup          положить трубку
  Во время звонка говори как обычно, кнопкой X.

ЕСЛИ КТО-ТО МЕШАЕТ
  /tv mute 25         не слышать игрока с ID 25
  /tv unmute 25       снова слышать
  /tv vol 25 50       сделать его тише (0-100)
  /tv report 25 кричит в микрофон
                      пожаловаться. Запись его голоса сохранится у тебя.

ДРУГОЕ
  /tv off   выключить голосовой чат        /tv on   включить
  /tv help  все команды


========================================
     КРАСИВОЕ МЕНЮ (по желанию)
========================================
Можно поставить библиотеку mimgui (сайт blast.hk, в поиске напиши mimgui).
Тогда команда /tv откроет меню с кнопками: громкость, рация, игроки рядом,
смена клавиш. Без mimgui всё работает через команды выше.


========================================
          ЕСЛИ НЕ РАБОТАЕТ
========================================

Нет надписи «TriniVoice загружен»
  -> Не установлен MoonLoader/SAMPFUNCS, или trinivoice.lua лежит не в папке
     moonloader. Повтори шаг 1 и шаг 2.

Пишет «нет связи» / нет надписи «подключено»
  -> Напиши в чат:  /tv server АДРЕС 7790
     (АДРЕС спроси у админа голосового чата).

Пишет «ваш ID уже занят»
  -> Подожди 10 секунд, всё заработает само.

Пишет «версия скрипта устарела»
  -> Возьми новый архив у админа и повтори шаг 2.

Пишет «микрофон недоступен»
  -> Сделай шаг 4.

Я никого не слышу
  -> У того, кто говорит, тоже должен стоять TriniVoice.
     Подойди ближе. Проверь, что звук в игре включён.

Ничего не помогло
  -> Отправь админу файл moonloader\moonloader.log


========================================
               ВАЖНО
========================================
* Скачивай TriniVoice только у админа своего сервера.
  Чужие «улучшенные» версии могут оказаться вирусом.
* Владелец голосового сервера видит твой ник и где ты стоишь в игре.
  Голос не шифруется — не говори того, что нельзя слышать чужим.
