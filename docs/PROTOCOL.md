# Протокол TriniVoice v3

UDP, little endian. Каждый пакет начинается с заголовка из 4 байт: `'T' 'V' <version=3> <type>`.
Пакеты другой версии отбрасываются.

**Токен сессии.** Сразу после заголовка в *каждом* пакете клиента идут 8 байт токена:
`HMAC-SHA256(секрет ретранслятора, "ip:port")[0..8]`. Клиент начинает с нулей; на STATE с неверным
токеном ретранслятор отвечает пакетом TOKEN (12 байт — меньше любого STATE) на адрес отправителя.
Остальные пакеты с неверным токеном молча отбрасываются. Так подделка IP-адреса отправителя не даёт ни
зарегистрироваться, ни говорить от чужого имени, ни использовать ретранслятор для усиления DDoS.
Секрет новый при каждом запуске ретранслятора; клиенты получают новый токен автоматически. `str` — длина u8 и байты (ники и комната — как есть,
тексты причин, паролей и уведомлений — UTF-8).

## Клиент → ретранслятор

| type | Пакет | Поля после заголовка |
|------|-------|----------------------|
| 0x01 | STATE | u16 playerId, f32 x, f32 y, f32 z, u8 interior, str room, str nick, str version, u16 radioFreq, str radioPass |
| 0x02 | VOICE | u16 seq, u8 mode, u8 codec, payload (1..512 байт) |
| 0x03 | BYE | — |
| 0x04 | CALL | u8 action (1 позвонить, 2 ответить, 3 положить трубку), u16 targetId |
| 0x05 | REPORT | u16 targetId, str reason |
| 0x06 | ADMIN | str key, u8 action (1 mute, 2 unmute, 3 ban, 4 unban, 5 kick), str nick, u32 minutes (0 = навсегда) |

- `room` — адрес SA-MP сервера `ip:port`. Игроки разных серверов не слышат друг друга.
- STATE отправляется 5 раз в секунду; через 10 секунд без STATE клиент считается отключённым.
- `radioFreq` — частота в МГц × 10 (911.5 → 9115), 0 — рация выключена.
- ADMIN можно слать без активной игровой сессии.

### Режимы речи (`mode`)

| mode | Режим | Дальность |
|------|-------|-----------|
| 1 | шёпот | 3 м |
| 2 | обычный | 15 м |
| 3 | крик | 40 м |
| 4 | мегафон (служебный транспорт) | 60 м |
| 5 | рация | вся частота + 8 м вокруг говорящего |
| 6 | телефон | собеседник + 5 м вокруг говорящего |

`codec`: 1 — G.711 u-law 8 кГц, 2 — Opus 16 кГц. Кадр 20 мс.

## Ретранслятор → клиент

| type | Пакет | Поля |
|------|-------|------|
| 0x81 | ACK | u8 status, u16 online, u16 radioListeners, u32 mutedSec, str latestVersion |
| 0x82 | VOICE | u16 speakerId, u16 seq, u8 mode, u8 codec, u8 route, payload |
| 0x83 | CALL | u8 event, u16 peerId, str peerNick |
| 0x84 | NOTICE | u8 code, str text |
| 0x85 | TOKEN | 8 байт токена сессии |

- ACK `status`: 0 OK, 1 сервер не разрешён, 2 ID занят, 3 бан, 4 голос выключен администратором
  (сессия работает, речь не пересылается), 5 версия клиента ниже `minClientVersion`,
  6 превышен `maxClientsPerIp` или `maxClients`.
- VOICE `route`: 0 — рядом (клиент проверяет расстояние сам), 1 — по рации, 2 — по телефону.
- CALL `event`: 1 входящий, 2 разговор начался, 3 завершён, 4 недоступен, 5 занято, 6 идёт вызов.
- NOTICE `code`: 1 команда администратора выполнена, 2 отказ, 3 жалоба принята,
  4 частота закрыта паролем, 5 вас отключили.

## Правила ретранслятора

- Голос «рядом» уходит игрокам той же комнаты и интерьера, если по последним координатам они ближе
  `range × rangeMargin + rangeSlack`.
- Рация: всем в комнате с той же частотой (route 1) и стоящим рядом без неё (route 0).
  Частоты из `radioPasswords` требуют пароль, иначе рация клиента считается выключенной.
- Телефон: только при активном звонке; собеседнику route 2, стоящим рядом route 0.
  Неотвеченный вызов сбрасывается через `callRingTimeoutMs`.
- Один `playerId` в комнате принадлежит одному адресу, пока тот не отключится.
- Не больше `maxVoicePacketsPerSec` голосовых пакетов в секунду с клиента; жалобы не чаще `reportCooldownMs`.
- Не больше `maxClientsPerIp` сессий с одного IP и `maxClients` всего.
- Команды администратора: только с `adminIps` (если задан); после `adminMaxFailures` неверных ключей IP
  игнорируется `adminLockMs`.
- Муты и баны хранятся в `data/moderation.json`; бан по нику переносится и на IP, с которого игрок был в сети.
  Жалобы дописываются в `data/reports.jsonl`.

## Проверки на клиенте

- Голос «рядом» играет, только если персонаж говорящего загружен в игре и стоит в пределах дальности
  режима. Мегафон принимается, только если говорящий сидит в служебном транспорте, иначе как крик.
- Рация принимается только при включённой рации, телефон — только от текущего собеседника.
- Сокет клиента «подключён» к адресу ретранслятора: пакеты с других адресов система отбрасывает.
- Текст от ретранслятора выводится в чат без цветовых кодов `{RRGGBB}` и управляющих символов,
  ники — только из разрешённых в SA-MP символов.
