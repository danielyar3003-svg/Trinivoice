# Протокол TriniVoice v1

UDP, little endian. Каждый пакет начинается с заголовка из 4 байт:
`'T' 'V' <version=1> <type>`.

## Клиент → ретранслятор

| type | Пакет | Поля после заголовка |
|------|-------|----------------------|
| 0x01 | STATE | u16 playerId, f32 x, f32 y, f32 z, u8 interior, u8 len + room, u8 len + nick |
| 0x02 | VOICE | u16 seq, u8 mode, u8 codec, payload (до 512 байт) |
| 0x03 | BYE   | — |

- `room`: адрес SA-MP сервера `ip:port`. Игроки разных серверов не слышат друг друга.
- STATE отправляется 5 раз в секунду. Через 10 секунд без STATE клиент считается отключённым.
- `mode`: 1 шёпот (3 м), 2 обычный (15 м), 3 крик (40 м).
- `codec`: 1 G.711 u-law 8 кГц, 2 Opus 16 кГц. Один кадр длится 20 мс.

## Ретранслятор → клиент

| type | Пакет | Поля |
|------|-------|------|
| 0x81 | ACK   | u8 status (0 OK, 1 сервер не разрешён, 2 ID занят, 3 бан), u16 число игроков с голосом в комнате |
| 0x82 | VOICE | u16 speakerId, u16 seq, u8 mode, u8 codec, payload |

## Правила ретранслятора

- Голос пересылается игрокам той же комнаты и того же интерьера, если по последним
  координатам они ближе, чем `range * rangeMargin + rangeSlack`.
- Один `playerId` в комнате принадлежит одному адресу, пока тот не отключится.
- Не больше `maxVoicePacketsPerSec` голосовых пакетов в секунду с одного клиента.

## Проверки на клиенте

Клиент играет звук, только если ped говорящего действительно загружен рядом в игре
и стоит в пределах радиуса режима. Поэтому подделанные координаты не помогут
подслушать или прокричать на всю карту.
