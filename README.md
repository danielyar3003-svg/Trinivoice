# TriniVoice

Голосовой чат по близости для SA-MP (Trinity RP). Работает на стороне клиента
и не требует плагина на игровом сервере:

- **клиент**: скрипт MoonLoader `client/moonloader/trinivoice.lua`. Пишет звук
  с микрофона и воспроизводит его через `bass.dll`, который уже есть в SA-MP;
- **ретранслятор**: `server/`, небольшой UDP-сервер на Node.js без зависимостей.
  Пересылает голос только тем игрокам, которые стоят рядом.

> ⚠️ Это сторонняя модификация. Перед распространением согласуйте её с администрацией
> Trinity RP: на сервере могут запрещать сторонние скрипты, а скрипт отправляет ваш
> ник, ID и координаты на ретранслятор. Голос слышат только те, у кого установлен скрипт.

## Возможности (v0.2)

- **Меню `/tv` на mimgui**: боковое меню с иконками, карточки, переключатели, шрифт Montserrat.
  Вкладки: Главная (дальность речи, клавиши, индикатор микрофона), Игроки рядом (громкость и
  заглушение каждого, кольцо «говорит» у аватара), Звук, Рации (скоро), Сервер (адрес, пинг, состояние).
  Клавиши переназначаются прямо в меню, Esc закрывает меню.

- Голос по близости: звук тише с расстоянием и слышно, с какой стороны говорят (стерео по камере).
- Три режима: шёпот (3 м), обычный (15 м), крик (40 м). По умолчанию переключаются клавишей **B**.
- «Нажми и говори» (по умолчанию **X**) или активация голосом с настраиваемым порогом.
- Метка `(( голос ))` над головой говорящего, цвет показывает режим. Строка состояния на экране.
- Выключение звука и громкость отдельно для каждого игрока (запоминается по нику), общая громкость, усиление микрофона.
- Мёртвый персонаж не может говорить. Пока открыт чат или диалог, клавиша не срабатывает.
- Кодеки: u-law (работает сразу) или Opus (лучше звук и меньше трафика, нужен `opus.dll`).
- Ретранслятор: отдельные комнаты для каждого SA-MP сервера, интерьеры изолированы, ограничение
  частоты пакетов, бан по нику, список разрешённых серверов.

## Установка клиента

1. Установите [MoonLoader](https://www.blast.hk/threads/13305/) и SAMPFUNCS. Библиотеки `inicfg`
   и `socket` (LuaSocket) входят в стандартную поставку MoonLoader.
2. Скопируйте содержимое `client/moonloader/` в папку `moonloader` игры:
   - `trinivoice.lua` — сам скрипт;
   - `lib/trinivoice/ui.lua` — меню;
   - `resource/trinivoice/` — шрифты Montserrat (лицензия OFL, файл `Montserrat-OFL.txt`).
3. Для меню установите **mimgui** (BlastHack, автор FYP) в `moonloader/lib/mimgui`.
   Для иконок — **fAwesome6** для mimgui (BlastHack) в `moonloader/lib/fAwesome6.lua`.
   Без fAwesome6 меню работает, но без иконок; без mimgui остаются только команды `/tv ...`.
4. Запустите игру, откройте меню `/tv`, вкладка «Сервер», впишите адрес ретранслятора.
   Без меню: `/tv server ВАШ_IP 7790`.
5. Необязательно: для Opus положите **32-битный** `opus.dll` в `moonloader/lib`
   и выберите Opus во вкладке «Звук» (или `/tv codec opus`). Opus должен стоять у всех, кто хочет вас слышать.

Настройки сохраняются в `moonloader/config/trinivoice.ini`.

### Команды

| Команда | Действие |
|---------|----------|
| `/tv` | открыть меню (без mimgui — состояние и справка) |
| `/tv help` | справка по командам |
| `/tv on` / `off` | включить / выключить |
| `/tv mode 1-3` | шёпот / обычный / крик |
| `/tv ptt` / `vad` | нажми и говори / активация голосом |
| `/tv threshold N` | порог активации голосом |
| `/tv mute ID` / `unmute ID` | выключить / вернуть звук игрока |
| `/tv vol ID 0-100` | громкость игрока |
| `/tv master 0-100` | общая громкость |
| `/tv gain 50-400` | усиление микрофона, % |
| `/tv codec ulaw` / `opus` | кодек |
| `/tv icons`, `/tv hud` | показать / скрыть метки и строку состояния |
| `/tv server HOST PORT` | адрес ретранслятора |

Клавиши меняются в меню (нажмите на клавишу и затем новую) или в ini (`ptt_key`, `mode_key`, это коды VK;
`mode_key = 0` отключает клавишу режима). Цвет меню — вкладка «Звук» → «Отображение».

## Запуск ретранслятора

Нужен VPS с открытым UDP-портом (по умолчанию 7790) и Node.js 18 или новее.

```bash
cd server
cp config.example.json config.json   # при желании отредактируйте
npm start
```

Или через Docker:

```bash
docker build -t trinivoice server
docker run -d -p 7790:7790/udp -v $PWD/server/config.json:/app/config.json trinivoice
```

### config.json

| Ключ | Описание |
|------|----------|
| `port` | UDP-порт |
| `allowedRooms` | список `ip:port` разрешённых SA-MP серверов (пусто = любые). Впишите адреса Trinity RP |
| `bannedNicks` | ники без доступа к голосу |
| `maxVoicePacketsPerSec` | ограничение частоты пакетов с клиента (50 пакетов/с = нормальная речь) |
| `rangeMargin`, `rangeSlack` | запас дальности на задержку обновления позиций |

Трафик: около 10 КБ/с от каждого говорящего на каждого слушателя рядом (u-law), с Opus примерно в 3 раза меньше.

## Тесты

```bash
cd server && npm test        # ретранслятор
luajit client/test/run.lua   # логика клиента: кодек, пакеты, громкость
luajit client/test/ui_test.lua  # меню на заглушке mimgui: все вкладки, клики, парность Push/Pop
```

`ui_test.lua` сверяет каждый вызов imgui со списком функций cimgui из mimgui 1.7.1
(`client/test/cimgui_names.txt`), так что опечатка в имени функции или неверный аргумент ловятся без игры.

Протокол описан в [docs/PROTOCOL.md](docs/PROTOCOL.md).

## Ограничения

- Собеседника слышно, только если у него тоже стоит скрипт.
- Ретранслятор верит клиенту, что тот — игрок с указанным ID. Защита: один ID на одного
  клиента в комнате, а слушатель проверяет, что говорящий реально стоит рядом в игре.
  Выдать себя за другого игрока, стоящего рядом, теоретически возможно.
- Скрипт ещё не проверялся в самой игре: тесты покрывают логику, протокол и меню (на заглушке mimgui),
  а работу с `bass.dll`, MoonLoader и настоящим mimgui нужно проверить на реальном клиенте.
- «Игроки рядом» показывает тех, кого вы слышали за последние 5 минут и кто сейчас рядом:
  узнать, у кого стоит скрипт, пока молчит, нельзя.

## Планы

Рации фракций по частотам, телефонные звонки (`/call`), мегафон, приглушение звука в
интерьерах и машинах, шумоподавление, админ-панель и жалобы с записью.
