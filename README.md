# TriniVoice

Голосовой чат для SA-MP (Trinity RP): речь рядом, рация, телефон и мегафон.
Работает на стороне клиента и не требует плагина на игровом сервере:

- **клиент**: скрипт MoonLoader `client/moonloader/trinivoice.lua` с модулями в `lib/trinivoice/`.
  Звук пишется и играется через `bass.dll`, который уже есть в SA-MP;
- **ретранслятор**: `server/`, UDP-сервер на Node.js без зависимостей. Пересылает голос тем, кто
  должен его слышать, и хранит муты, баны и жалобы.

> ⚠️ Это сторонняя модификация. Перед распространением согласуйте её с администрацией Trinity RP:
> на сервере могут запрещать сторонние скрипты, а скрипт отправляет ваш ник, ID и координаты на
> ретранслятор. Голос слышат только те, у кого установлен скрипт.

## Возможности (v0.3)

**Речь рядом**
- Громкость падает с расстоянием, звук объёмный: слышно, с какой стороны говорят.
- Шёпот 3 м, обычный 15 м, крик 40 м (клавиша **B**). В служебной машине крик становится
  **мегафоном** на 60 м с характерным звуком.
- Через стены и в машине голос звучит глухо и тише.
- Нажми и говори (**X**) или активация голосом с настраиваемым порогом.

**Рация** (клавиша **Z**)
- Частоты от 1.0 до 6553.5 МГц, слышно на любом расстоянии всем на той же частоте.
- Звук рации: узкая полоса, перегруз, шипение в начале и в конце фразы.
- Закрытые частоты фракций с паролем, избранные частоты в ini.
- Стоящие рядом слышат, что вы говорите в рацию.

**Телефон**
- `/tv call ID`, мелодия входящего, гудки, «Ответить / Сбросить» в меню, длительность разговора.
- Телефонный звук; стоящие рядом слышат вашу половину разговора.
- Автозвонки: если сервер пишет о звонке в чат, голос соединяется сам (`/tv autocall`).

**Меню `/tv` на mimgui**: боковое меню с иконками, вкладки Главная, Игроки рядом, Звук, Рация, Сервер,
карточка звонка, выбор цвета, переназначение клавиш, Esc закрывает меню.

**Модерация**
- Жалоба из меню или `/tv report ID причина`: последние 30 секунд голоса сохраняются у вас в WAV,
  жалоба уходит в журнал ретранслятора.
- Администраторы ретранслятора: mute, unmute, ban (по нику и IP), unban, kick.
- Список разрешённых SA-MP серверов, ограничение частоты пакетов.

**Обновления**: ретранслятор сообщает последнюю версию, клиент показывает уведомление;
слишком старые клиенты не пускаются (`minClientVersion`).

## Установка клиента

Скачайте `TriniVoice-<версия>-client.zip` (собирается `scripts/build-release.sh`) или возьмите файлы из
`client/moonloader/`:

1. Нужны [MoonLoader](https://www.blast.hk/threads/13305/) и SAMPFUNCS.
2. Скопируйте папку `moonloader` в папку игры: `trinivoice.lua`, `lib/trinivoice/`, `resource/trinivoice/`
   (шрифты Montserrat, лицензия OFL).
3. Для меню установите **mimgui** (BlastHack, автор FYP). Для иконок — **fAwesome6** для mimgui (BlastHack)
   в `moonloader/lib/fAwesome6.lua`. Для автозвонков — **SAMP.Lua**. Без fAwesome6 меню работает без иконок,
   без mimgui остаются команды.
4. В игре: `/tv` → вкладка «Сервер» → адрес ретранслятора. Без меню: `/tv server АДРЕС 7790`.
5. Необязательно: **32-битный** `opus.dll` в `moonloader/lib` и кодек Opus во вкладке «Звук» — лучше звук
   и меньше трафика, но `opus.dll` нужен всем, кто хочет вас слышать.

Настройки: `moonloader/config/trinivoice.ini`. Избранные частоты — раздел `[radio_presets]`:

```ini
[radio_presets]
LSPD=911.0
EMS=912.0
```

### Команды

| Команда | Действие |
|---------|----------|
| `/tv` | меню (без mimgui — состояние и справка) |
| `/tv help` | справка |
| `/tv on` / `off` | включить / выключить |
| `/tv mode 1-3`, `/tv ptt` / `vad`, `/tv threshold N` | дальность, способ активации, порог |
| `/tv radio on` / `off` / `911.0`, `/tv radiopass ПАРОЛЬ` | рация |
| `/tv call ID`, `/tv accept`, `/tv decline` / `hangup` | телефон |
| `/tv autocall on` / `off`, `/tv autocall start ШАБЛОН`, `/tv autocall end ШАБЛОН` | автозвонки |
| `/tv mute ID` / `unmute ID`, `/tv vol ID 0-100`, `/tv master 0-100`, `/tv gain 50-400` | громкость |
| `/tv report ID причина` | жалоба с записью голоса |
| `/tv codec ulaw` / `opus`, `/tv icons`, `/tv hud`, `/tv server HOST PORT` | прочее |
| `/tv adminkey КЛЮЧ`, `/tv admin mute\|unmute\|ban\|unban\|kick НИК [минуты]` | администрирование |

**Автозвонки.** Шаблон — Lua-шаблон по тексту сообщения сервера, захват `(...)` — ник или ID собеседника.
Пример (подставьте настоящие фразы Trinity RP):

```
/tv autocall start Входящий звонок от (%S+)
/tv autocall start Вы звоните (%S+)
/tv autocall end Звонок завершен
/tv autocall on
```

У звонящего и принимающего фразы обычно разные — каждый настраивает ту, что видит сам.

## Ретранслятор

Нужен Node.js 18+ и открытый UDP-порт (по умолчанию 7790). Без VPS: на своём ПК с пробросом порта,
через playit.gg (поддерживает UDP) или на бесплатном облачном сервере (Oracle Cloud Always Free).

```bash
cd server
cp config.example.json config.json
npm start
```

Docker:

```bash
docker build -t trinivoice server
docker run -d -p 7790:7790/udp -v $PWD/server/config.json:/app/config.json -v $PWD/data:/app/data trinivoice
```

### config.json

| Ключ | Описание |
|------|----------|
| `port`, `dataDir` | UDP-порт и папка для `moderation.json` и `reports.jsonl` |
| `allowedRooms` | `ip:port` разрешённых SA-MP серверов (пусто = любые). Впишите адреса Trinity RP |
| `radioPasswords` | закрытые частоты: `{ "911.0": "пароль" }` |
| `admins` | `[{ "name": "...", "key": "..." }]`, ключ не короче 8 символов |
| `latestClientVersion`, `minClientVersion` | уведомление об обновлении и минимальная версия клиента |
| `bannedNicks` | постоянные баны по нику |
| `callRingTimeoutMs`, `reportCooldownMs` | время вызова и пауза между жалобами |
| `maxVoicePacketsPerSec`, `rangeMargin`, `rangeSlack` | ограничение пакетов и запас дальности |

Трафик: около 10 КБ/с от каждого говорящего на каждого слушателя (u-law), с Opus примерно втрое меньше.

## Сборка и тесты

```bash
scripts/build-release.sh         # тесты + dist/TriniVoice-<версия>-client.zip и -relay.zip
cd server && npm test            # ретранслятор: протокол, рация, звонки, модерация
luajit client/test/run.lua       # протокол клиента, кодек, эффекты, WAV
luajit client/test/ui_test.lua   # меню на заглушке mimgui (сверка с API mimgui 1.7.1)
client/test/e2e.sh               # ретранслятор + 3 клиента в эмуляции MoonLoader (нужен lua-socket)
```

`e2e.sh` запускает настоящий `trinivoice.lua` трижды с поддельными функциями игры и `bass.dll` и проверяет
по UDP: речь рядом, стены, рацию и закрытую частоту, мегафон, звонок и автозвонок, жалобу с WAV, мут от
администратора и уведомление об обновлении. Те же тесты гоняет GitHub Actions (`.github/workflows/test.yml`).

Протокол: [docs/PROTOCOL.md](docs/PROTOCOL.md).

## Ограничения

- Скрипт не запускался в настоящей игре: тесты эмулируют MoonLoader, `bass.dll` и mimgui. Работу с реальным
  клиентом SA-MP нужно проверить вживую.
- Собеседника слышно, только если у него тоже стоит скрипт.
- Ретранслятор верит клиенту, что тот — игрок с указанным ID. Защита: один ID на клиента в комнате,
  слушатель проверяет, что говорящий реально стоит рядом, жалобы и баны по нику и IP. Полностью исключить
  подмену без поддержки со стороны игрового сервера нельзя.
- Пароль частоты знает любой, кому его сказали: это не проверка принадлежности к фракции.
- Автообновления нет намеренно: скачивать и запускать код из сети небезопасно. Клиент только сообщает о
  новой версии.
