# TriniVoice — установка

TriniVoice состоит из двух частей:

| Часть | Кому нужна | Архив |
|-------|-----------|-------|
| Скрипт для игры | каждому игроку | `TriniVoice-0.3.0-client.zip` |
| Ретранслятор (голосовой сервер) | одному человеку, который его запускает | `TriniVoice-0.3.0-relay.zip` |

Голос идёт от игрока к ретранслятору и от него к тем, кто должен его слышать. Без запущенного
ретранслятора скрипт не работает, поэтому сначала его поднимает владелец, а потом игроки вписывают его адрес.

> ⚠️ Перед раздачей игрокам согласуйте скрипт с администрацией Trinity RP: сторонние скрипты могут быть
> запрещены, а TriniVoice отправляет ник, ID и координаты игрока на ретранслятор.

## Часть 1. Игроку

### Что должно быть установлено

1. **GTA San Andreas** с **SA-MP 0.3.7**.
2. **MoonLoader** и **SAMPFUNCS** — ставятся вместе, инструкция на BlastHack:
   <https://www.blast.hk/threads/13305/>.
3. **mimgui** — библиотека меню (BlastHack, автор FYP). После установки должна появиться папка
   `moonloader/lib/mimgui`. Без неё меню не откроется, но голос будет работать через команды `/tv ...`.
4. Необязательно: **SAMP.Lua** (`moonloader/lib/samp/events.lua`) — только для автоматических звонков
   по сообщениям сервера.

Иконки (Font Awesome 4.7) и шрифты (Montserrat) уже лежат в архиве, отдельно ставить ничего не нужно.

### Установка

1. Распакуйте `TriniVoice-0.3.0-client.zip`.
2. Скопируйте папку `moonloader` из архива в папку с игрой (туда, где `gta_sa.exe`) и согласитесь
   на объединение папок. Должно получиться:

```
GTA San Andreas/
└── moonloader/
    ├── trinivoice.lua
    ├── lib/
    │   └── trinivoice/
    │       ├── audio.lua
    │       ├── protocol.lua
    │       └── ui.lua
    └── resource/
        └── trinivoice/
            ├── fontawesome-webfont.ttf     ← иконки
            ├── Montserrat-Medium.ttf
            ├── Montserrat-SemiBold.ttf
            └── Montserrat-Bold.ttf
```

3. Запустите игру и зайдите на сервер. В чате появится: `[TriniVoice] v0.3.0 загружен`.
4. Наберите `/tv` — откроется меню. Вкладка **«Сервер»** → впишите адрес и порт ретранслятора
   (их даёт владелец) → **«Подключиться»**. Без меню: `/tv server АДРЕС ПОРТ`.
5. Внизу бокового меню должно загореться **«На связи»**.

### Как пользоваться

| Клавиша / команда | Что делает |
|-------------------|-----------|
| **X** (держать) | говорить |
| **B** | дальность: шёпот 3 м → обычный 15 м → крик 40 м |
| **Z** (держать) | говорить в рацию (если рация включена) |
| `/tv` | меню; **Esc** закрывает |
| `/tv radio 911.0`, `/tv radio off` | рация |
| `/tv call ID`, `/tv accept`, `/tv hangup` | телефон |
| `/tv report ID причина` | жалоба с записью голоса |
| `/tv help` | все команды |

Клавиши меняются в меню: нажмите на клавишу, затем новую.
Настройки сохраняются в `moonloader/config/trinivoice.ini`.

**Лучший звук (необязательно):** положите **32-битный** `opus.dll` в `moonloader/lib` и выберите Opus во
вкладке «Звук». Opus должен стоять у всех, кто хочет вас слышать, иначе оставьте u-law.

## Часть 2. Владельцу ретранслятора

Ретранслятор — маленькая программа на Node.js. Её можно запустить на своём компьютере или на сервере.
Она должна работать всё время, пока люди играют.

### Windows (свой компьютер)

1. Установите **Node.js LTS** с <https://nodejs.org> (галочки по умолчанию).
2. Распакуйте `TriniVoice-0.3.0-relay.zip`, например в `C:\TriniVoice-relay`.
3. Скопируйте `config.example.json` в `config.json` и откройте его в Блокноте:
   - `admins` → замените ключ на длинный случайный (это пароль администратора голосового чата);
   - `radioPasswords` → пароли закрытых частот фракций (или `{}`);
   - `allowedRooms` → адреса серверов Trinity RP в виде `"ip:port"` (или `[]`, чтобы пускать с любого).
4. Откройте командную строку в этой папке и запустите:

```
node src\index.js config.json
```

   Появится `relay listening on udp://0.0.0.0:7790`. Окно не закрывайте.
5. Разрешите порт в брандмауэре (командная строка **от имени администратора**):

```
netsh advfirewall firewall add rule name="TriniVoice" dir=in action=allow protocol=UDP localport=7790
```

6. Чтобы к вам могли подключиться из интернета, выберите одно:
   - **проброс порта** в роутере: UDP 7790 на ваш компьютер; игрокам даёте внешний IP
     (если IP «серый» — CGNAT, — этот способ не сработает);
   - **playit.gg**: бесплатный туннель с поддержкой UDP, роутер настраивать не нужно; игрокам даёте адрес,
     который выдаст playit.

### Linux / VPS / бесплатный облачный сервер

```bash
unzip TriniVoice-0.3.0-relay.zip -d trinivoice && cd trinivoice
cp config.example.json config.json && nano config.json
node src/index.js config.json
```

Или в Docker: `docker build -t trinivoice . && docker run -d -p 7790:7790/udp -v $PWD/config.json:/app/config.json -v $PWD/data:/app/data trinivoice`.

### Модерация

- Ключ администратора вводится в игре: `/tv adminkey КЛЮЧ`.
- Команды: `/tv admin mute НИК 30` (минуты, 0 = навсегда), `unmute НИК`, `ban НИК 0`, `unban НИК`, `kick НИК`.
- Жалобы игроков: `data/reports.jsonl`. Муты и баны: `data/moderation.json`.
- Записи голоса по жалобам сохраняются **у того, кто пожаловался**: `moonloader/config/trinivoice/reports/*.wav`.

## Проверка

1. Два игрока ставят скрипт и подключаются к одному ретранслятору. У обоих «На связи».
2. Встаньте рядом, один держит **X** и говорит — второй слышит, над головой говорящего `(( голос ))`.
3. `/tv radio 100.0` у обоих, разойдитесь подальше, держите **Z** — слышно с эффектом рации.

## Если что-то не работает

| Проблема | Что сделать |
|----------|-------------|
| Нет сообщения «загружен» | Не установлены MoonLoader/SAMPFUNCS или `trinivoice.lua` не в папке `moonloader` |
| `/tv` пишет справку вместо меню | Не установлен mimgui |
| Меню без иконок | Нет файла `moonloader/resource/trinivoice/fontawesome-webfont.ttf` |
| «Нет связи» | Неверный адрес/порт, ретранслятор не запущен, закрыт порт в брандмауэре или роутере |
| «ваш ID уже занят» | Перезайдите через 10 секунд — старое подключение ещё не отвалилось |
| Не слышно собеседника | У него нет скрипта, он далеко, вы в разных интерьерах, или он говорит через Opus, а у вас нет `opus.dll` |
| «микрофон недоступен» | Windows → Параметры → Конфиденциальность → Микрофон → разрешить классическим приложениям |
| «версия скрипта устарела» | Скачайте свежий архив у владельца ретранслятора |

Если не помогло — пришлите файл `moonloader/moonloader.log`.
