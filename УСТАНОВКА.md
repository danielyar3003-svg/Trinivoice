# TriniVoice — установка

> Короткие инструкции простым языком: **ИНСТРУКЦИЯ_АДМИНУ.txt** (Oracle, шаг за шагом) и
> **ПРОЧИТАЙ_МЕНЯ.txt** для игроков. Здесь — подробная версия.
>
> На Oracle установщик сам собирает `~/TriniVoice-players.zip`, в который уже вписан адрес сервера:
> игрокам достаточно распаковать его в папку с игрой.

TriniVoice состоит из двух частей:

| Часть | Кому нужна | Архив |
|-------|-----------|-------|
| Скрипт для игры | каждому игроку | `TriniVoice-0.4.0-client.zip` |
| Ретранслятор (голосовой сервер) | одному человеку, который его запускает | `TriniVoice-0.4.0-relay.zip` |

Голос идёт от игрока к ретранслятору и от него к тем, кто должен его слышать. Без запущенного
ретранслятора скрипт не работает, поэтому сначала его поднимает владелец, а потом игроки вписывают его адрес.

> ⚠️ Перед раздачей игрокам согласуйте скрипт с администрацией Trinity RP: сторонние скрипты могут быть
> запрещены, а TriniVoice отправляет ник, ID и координаты игрока на ретранслятор.

## Часть 1. Игроку

### Что должно быть установлено

1. **GTA San Andreas** с **SA-MP 0.3.7**.
2. **MoonLoader** и **SAMPFUNCS** — ставятся вместе, инструкция на BlastHack:
   <https://www.blast.hk/threads/13305/>.
3. **mimgui** — библиотека меню (BlastHack, автор FYP). После установки должна появиться папка
   `moonloader/lib/mimgui`. Без неё меню не откроется, но голос будет работать через команды `/tv ...`.
4. Необязательно: **SAMP.Lua** (`moonloader/lib/samp/events.lua`) — только для автоматических звонков
   по сообщениям сервера.

Иконки (Font Awesome 4.7) и шрифты (Montserrat) уже лежат в архиве, отдельно ставить ничего не нужно.

### Установка

1. Распакуйте `TriniVoice-0.4.0-client.zip`.
2. Скопируйте папку `moonloader` из архива в папку с игрой (туда, где `gta_sa.exe`) и согласитесь
   на объединение папок. Должно получиться:

```
GTA San Andreas/
└── moonloader/
    ├── trinivoice.lua
    ├── lib/
    │   └── trinivoice/
    │       ├── audio.lua
    │       ├── protocol.lua
    │       └── ui.lua
    └── resource/
        └── trinivoice/
            ├── fontawesome-webfont.ttf     ← иконки
            ├── Montserrat-Medium.ttf
            ├── Montserrat-SemiBold.ttf
            └── Montserrat-Bold.ttf
```

3. Запустите игру и зайдите на сервер. В чате появится: `[TriniVoice] v0.4.0 загружен`.
4. Наберите `/tv` — откроется меню. Вкладка **«Сервер»** → впишите адрес и порт ретранслятора
   (их даёт владелец) → **«Подключиться»**. Без меню: `/tv server АДРЕС ПОРТ`.
5. Внизу бокового меню должно загореться **«На связи»**.

### Как пользоваться

| Клавиша / команда | Что делает |
|-------------------|-----------|
| **X** (держать) | говорить |
| **B** | дальность: шёпот 3 м → обычный 15 м → крик 40 м |
| **Z** (держать) | говорить в рацию (если рация включена) |
| `/tv` | меню; **Esc** закрывает |
| `/tv radio 911.0`, `/tv radio off` | рация |
| `/tv call ID`, `/tv accept`, `/tv hangup` | телефон |
| `/tv report ID причина` | жалоба с записью голоса |
| `/tv help` | все команды |

Клавиши меняются в меню: нажмите на клавишу, затем новую.
Настройки сохраняются в `moonloader/config/trinivoice.ini`.

**Лучший звук (необязательно):** положите **32-битный** `opus.dll` в `moonloader/lib` и выберите Opus во
вкладке «Звук». Opus должен стоять у всех, кто хочет вас слышать, иначе оставьте u-law.

## Часть 2. Владельцу ретранслятора

Ретранслятор — маленькая программа на Node.js. Её можно запустить на своём компьютере или на сервере.
Она должна работать всё время, пока люди играют.

### Windows (свой компьютер)

1. Установите **Node.js LTS** с <https://nodejs.org> (галочки по умолчанию).
2. Распакуйте `TriniVoice-0.4.0-relay.zip`, например в `C:\TriniVoice-relay`.
3. Скопируйте `config.example.json` в `config.json` и откройте его в Блокноте:
   - `admins` → замените ключ на длинный случайный (это пароль администратора голосового чата);
   - `radioPasswords` → пароли закрытых частот фракций (или `{}`);
   - `allowedRooms` → адреса серверов Trinity RP в виде `"ip:port"` (или `[]`, чтобы пускать с любого).
4. Откройте командную строку в этой папке и запустите:

```
node src\index.js config.json
```

   Появится `relay listening on udp://0.0.0.0:7790`. Окно не закрывайте.
5. Разрешите порт в брандмауэре (командная строка **от имени администратора**):

```
netsh advfirewall firewall add rule name="TriniVoice" dir=in action=allow protocol=UDP localport=7790
```

6. Чтобы к вам могли подключиться из интернета, выберите одно:
   - **проброс порта** в роутере: UDP 7790 на ваш компьютер; игрокам даёте внешний IP
     (если IP «серый» — CGNAT, — этот способ не сработает);
   - **playit.gg**: бесплатный туннель с поддержкой UDP, роутер настраивать не нужно; игрокам даёте адрес,
     который выдаст playit.

### Oracle Cloud (бесплатно, работает круглосуточно)

**1. Сервер.** Зарегистрируйтесь на <https://cloud.oracle.com> (карту просят для проверки, за ресурсы
Always Free деньги не списываются). Регион выберите ближе к игрокам, например Frankfurt: поменять его потом нельзя.
Дальше: меню → **Compute → Instances → Create instance**:

- **Image**: Canonical **Ubuntu 24.04** (важно: на 22.04 слишком старый Node.js);
- **Shape**: с пометкой *Always Free eligible* — `VM.Standard.E2.1.Micro` или `VM.Standard.A1.Flex` (1 OCPU, 6 GB);
- **Networking**: создать новую сеть (VCN) с публичной подсетью, *Assign a public IPv4 address* — включено;
- **Add SSH keys**: *Generate a key pair for me* → **Save private key**. Этот файл — ключ от сервера:
  не теряйте и никому не отправляйте;
- **Create**. Через минуту на странице сервера появится *Public IP address*.

**2. Открыть порт в сети Oracle.** На странице сервера: ссылка на **Subnet** → **Security Lists** →
*Default Security List* → **Add Ingress Rules**:

| Поле | Значение |
|------|----------|
| Source CIDR | `0.0.0.0/0` |
| IP Protocol | **UDP** |
| Destination Port Range | `7790` |

Больше ничего не открывайте: SSH (порт 22) уже открыт, вход только по ключу.

**3. Подключиться.** На Windows 10/11 откройте PowerShell в папке с ключом и архивом:

```
ssh -i .\ssh-key.key ubuntu@ПУБЛИЧНЫЙ_IP
```

Если ssh пишет `UNPROTECTED PRIVATE KEY FILE`, один раз выполните
`icacls .\ssh-key.key /inheritance:r /grant:r "${env:USERNAME}:R"` и подключитесь снова.

**4. Залить и установить.** Во втором окне PowerShell:

```
scp -i .\ssh-key.key TriniVoice-0.4.0-relay.zip ubuntu@ПУБЛИЧНЫЙ_IP:~
```

На сервере (в окне ssh):

```bash
sudo apt-get install -y unzip
unzip -o TriniVoice-0.4.0-relay.zip -d trinivoice && cd trinivoice
sudo bash deploy/install-ubuntu.sh
```

Скрипт ставит Node.js из репозитория Ubuntu, создаёт системного пользователя без права входа, кладёт
программу в `/opt/trinivoice`, открывает UDP 7790 в брандмауэре самого сервера, включает автообновления
безопасности Ubuntu и запускает ретранслятор как службу в песочнице (автозапуск после перезагрузки).
В конце он покажет **ключ администратора** — сохраните его — и адрес для игроков.

**5. Настроить.** `sudo nano /etc/trinivoice/config.json`:

- `allowedRooms` — адреса серверов Trinity RP (`"ip:port"`), чтобы ретранслятором не пользовались чужие;
- `radioPasswords` — закрытые частоты: `{ "911.0": "пароль-для-LSPD" }`;
- `adminIps` — по желанию ваш домашний IP, тогда админ-команды примутся только с него.

Сохранить: Ctrl+O, Enter, Ctrl+X. Применить: `sudo systemctl restart trinivoice`.

**6. Проверить.** `sudo systemctl status trinivoice` — должно быть `active (running)`;
журнал: `sudo journalctl -u trinivoice -f`. Игроки вписывают в игре `ПУБЛИЧНЫЙ_IP` и порт `7790`.

**Обновление:** залейте новый архив и снова выполните шаг 4 — настройки и данные сохранятся.
**Резервная копия:** `/etc/trinivoice` (настройки) и `/var/lib/trinivoice` (баны, муты, жалобы).
**Если сервер пропал:** Oracle может остановить бесплатный сервер, который долго почти не нагружен.
Запустите его в консоли (*Start*), ретранслятор поднимется сам.

### Linux / VPS (другие хостинги)

Тот же `sudo bash deploy/install-ubuntu.sh` на Ubuntu 24.04; откройте UDP 7790 в панели хостинга.
Или Docker: `docker build -t trinivoice . && docker run -d --restart unless-stopped -p 7790:7790/udp -v $PWD/config.json:/app/config.json:ro -v $PWD/data:/app/data trinivoice`
(в контейнере программа работает не от root).

### Модерация

- Ключ администратора вводится в игре: `/tv adminkey КЛЮЧ`.
- Команды: `/tv admin mute НИК 30` (минуты, 0 = навсегда), `unmute НИК`, `ban НИК 0`, `unban НИК`, `kick НИК`.
- Жалобы игроков: `data/reports.jsonl`. Муты и баны: `data/moderation.json`.
- Записи голоса по жалобам сохраняются **у того, кто пожаловался**: `moonloader/config/trinivoice/reports/*.wav`.

## Безопасность

### Что защищено

- **Подделка IP.** Каждый пакет клиента содержит токен сессии, который ретранслятор выдаёт только на
  настоящий адрес игрока. Поэтому нельзя говорить от чужого имени, подставив его IP, и нельзя использовать
  ретранслятор, чтобы завалить чей-то IP трафиком (ответ без токена меньше запроса).
- **IP игроков не видны другим игрокам.** Голос идёт через ретранслятор; игроки знают только ник и ID.
- **Перегрузка.** Не больше 60 голосовых пакетов в секунду с игрока, 4 подключений с одного IP и 2000 всего.
- **Подбор ключа админа.** После 5 неверных ключей IP блокируется на 15 минут; можно разрешить
  админ-команды только со своего IP (`adminIps`).
- **Подслушивание через подделанные координаты.** Клиент играет голос «рядом», только если говорящий
  действительно стоит рядом в игре.
- **Подделка сообщений.** Текст от ретранслятора выводится в чат без цветовых кодов, с пометкой `[TriniVoice]`.
- **Сервер.** Служба работает от отдельного пользователя без прав входа, в песочнице systemd: пишет только
  в свою папку данных, не может получить права root. Открыт один UDP-порт, SSH только по ключу,
  обновления безопасности Ubuntu ставятся сами.
- **Код.** Ретранслятор не использует сторонних npm-пакетов, скрипт не скачивает и не запускает код из сети.

### Что важно знать (честно)

- **Голос не шифруется.** Его может услышать тот, кто контролирует сеть между игроком и ретранслятором
  (например, общий Wi-Fi), и **владелец ретранслятора**, если изменит программу. Не говорите в игре того,
  что нельзя слышать посторонним.
- **Владелец ретранслятора видит** ники, ID, координаты и IP подключённых игроков; IP пишутся в журнал и в
  жалобы. Предупредите игроков об этом.
- **Ключ админа и пароли частот** передаются без шифрования. Используйте длинный случайный ключ (скрипт
  установки создаёт такой) и `adminIps`; пароли частот — защита «от случайных», а не от взлома.
- **Подмена игрока полностью не исключена.** Ретранслятор не может спросить у сервера Trinity, кто есть кто.
  Игрок с TriniVoice рядом с жертвой без TriniVoice теоретически может говорить «за неё». На это — жалобы
  с записью и баны по нику и IP.
- **Правила Trinity RP.** Сторонние скрипты могут быть запрещены. Согласуйте с администрацией до раздачи.
- **Берите скрипт только из одного источника** — от вас. Lua-скрипт MoonLoader может всё, что может игра на
  компьютере игрока; чужая «доработанная» копия может быть вредоносной.

## Проверка

1. Два игрока ставят скрипт и подключаются к одному ретранслятору. У обоих «На связи».
2. Встаньте рядом, один держит **X** и говорит — второй слышит, над головой говорящего `(( голос ))`.
3. `/tv radio 100.0` у обоих, разойдитесь подальше, держите **Z** — слышно с эффектом рации.

## Если что-то не работает

| Проблема | Что сделать |
|----------|-------------|
| Нет сообщения «загружен» | Не установлены MoonLoader/SAMPFUNCS или `trinivoice.lua` не в папке `moonloader` |
| `/tv` пишет справку вместо меню | Не установлен mimgui |
| Меню без иконок | Нет файла `moonloader/resource/trinivoice/fontawesome-webfont.ttf` |
| «Нет связи» | Неверный адрес/порт, ретранслятор не запущен, закрыт порт в брандмауэре или роутере |
| «ваш ID уже занят» | Перезайдите через 10 секунд — старое подключение ещё не отвалилось |
| Не слышно собеседника | У него нет скрипта, он далеко, вы в разных интерьерах, или он говорит через Opus, а у вас нет `opus.dll` |
| «микрофон недоступен» | Windows → Параметры → Конфиденциальность → Микрофон → разрешить классическим приложениям |
| «версия скрипта устарела» | Скачайте свежий архив у владельца ретранслятора |

Если не помогло — пришлите файл `moonloader/moonloader.log`.
